QuietPhone 软件静音插件（Dopamine Rootless / iOS 15+）已收录到 `rootless` 源：

- 添加源：`https://wwangmc.github.io/repo/rootless/`，搜索 **QuietPhone**。
- 开源代码和使用说明：[wwangmc/QuietPhone](https://github.com/wwangmc/QuietPhone)，MIT 许可证。
- 最新 0.1.1 安装后默认开启静音，修复设置入口不显示的问题；已在另一台此前无效的 iPhone X / iOS 16.1.1 上由用户确认生效。其他设备和输出方式需单独实测。
