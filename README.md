# repo

QuietPhone 软件静音插件已提供有根和无根两个版本：

- 有根 iOS 14+：`https://wwangmc.github.io/repo/`，搜索 **QuietPhone**。
- 无根 Dopamine / iOS 15/16：`https://wwangmc.github.io/repo/rootless/`，搜索 **QuietPhone**。
- 开源代码和使用说明：[wwangmc/QuietPhone](https://github.com/wwangmc/QuietPhone)，MIT 许可证。
- 最新 0.1.2 增加有根版，安装后默认开启静音并提供设置开关。0.1.1 无根版已在另一台此前无效的 iPhone X / iOS 16.1.1 上由用户确认生效。有根版和其他设备、输出方式仍需单独实测。
